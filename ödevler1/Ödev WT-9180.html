CSS Nedir?

  • CSS, HTML veya diğer belge türleri üzerindeki öğelerin (elementlerin) görünümünü kontrol etmek için kullanılan bir stil dilidir.
  • Web tarayıcıları, HTML belgelerini render ederken CSS kurallarını kullanarak öğelerin nasıl görüneceğini belirler.
